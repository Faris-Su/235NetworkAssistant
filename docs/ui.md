# 界面设计（Source of Truth）

## 1. 整体结构

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部设备状态栏：设备名称 | 管理 IP | 连接方式 | 连接状态 | Session │
├────────┬─────────────────────────────────────────────────────┤
│ 左侧   │                                                     │
│ 导航   │                   中央内容区                         │
│        │                                                     │
├────────┴─────────────────────────────────────────────────────┤
│ 底部状态栏：当前状态 / 操作提示                         时间  │
└──────────────────────────────────────────────────────────────┘
```

导航（12 项）：🏠 概览、🔌 连接、💻 CLI、🔌 端口、🟢 VLAN、🟠 Trunk、🟣 LLDP、
🔎 MAC/IP、📊 设备、💾 备份、📚 资源库（VLAN/IP/场所查询）、⚙ 设置。

> 说明：提示词给出的导航为 11 项且未包含独立资源库入口，而 V0.1 明确要求
> “交换机地址簿”“VLAN/IP 查询”“楼栋/房间查询”。地址簿放在【连接】页，
> VLAN/IP/场所查询额外增加【资源库】页，未新增任何超出 V0.1 的功能。

风格：简洁、专业、高信息密度、低资源消耗。不做炫酷网络大屏。

## 2. 视觉约束

- 颜色：石墨蓝灰导航 + 浅青灰工作区 + 矿物青绿强调色；成功 / 注意 / 危险使用独立语义色，不借强调色代替状态。
- 字体：`Microsoft YaHei UI, Segoe UI`；终端区 `Consolas`
- **禁止**：模糊、透明、阴影、动画、粒子、动态背景、实时动态图表、WebView、Electron
- 表格开启行/列虚拟化与 Recycling；行高随内容，最小 30 DIP，字号 14 DIP

### 2026-10-08 静态样式打磨

- 沿用现有原生 WPF 与语义配色：面板 5 DIP、按钮 3 DIP 轻微圆角，没有动画和特效。
- 页面标题 22 DIP、分区标题 17 DIP、标准正文 14 DIP、辅助说明不低于 13 DIP；字号档位为小 13 / 标准 14 / 大 16 DIP。
- 间距遵循 4 / 8 / 12 / 16 DIP 节奏：主窗口内容边距 16×12、面板内边距 16、常用控件间隔 8 DIP；窗口随 DPI 缩放使用自动行高。
- 输入控件、按钮、选项控件采用 14 DIP；输入框至少 34 DIP 高，按钮至少 36 DIP 高；数据表格 14 DIP 字号、30 DIP 最小行高。
- 导航选中项采用深底、浅青绿文字与左侧色条；表格白底、浅青灰斑马行、内边距和选中态保持统一。
- 全局次级文字提高对比度；按钮、输入框和表格统一尺寸，面板与按钮使用同一克制圆角。
- 主窗口左侧导航改为石墨蓝灰，选中态与浅青灰内容区使用同一青绿色强调色系。
- 概览页删去重复说明和水印，突出设备/网络状态；Session ID 与管理 IP 解释改为悬停查看，操作结果仍在页面显示。
- 概览的当前设备摘要横跨内容区顶部，常用操作和近期操作分别落在左右工作区，避免顶部信息只占半栏。
- 连接页移除地址簿重复来源说明和重复的协议/权限解释，详细原理保留在控件提示中，连接、自检和错误结果仍可见。
- 连接页小窗口下正文可竖向滚动；连接/权限操作固定在底部，地址簿表格保留有限视口高度（避免外层滚动挤压表格）。
- CLI 工具条明确分成设备操作与终端显示两组；移除冗长操作说明和重复的保存配置入口，保留一行快捷键提示；终端输出、输入行为与缓冲统计不变。
- CLI 底部仅常驻当前状态，缓冲信息悬停查看；终端模式说明由终端本身 ToolTip 提供。
- 备份页参数区与文件列表按可用高度分配，各自滚动，文件列表至少留 140 DIP。

## 4. CLI 性能设计（Phase 1 实现）

```
Device Stream → Receive Buffer → 批量 UI 更新 → Terminal
```

- 禁止每收到一个字符就刷新 UI；禁止每收到一行就重建整个 TextBox 内容
- 默认合并刷新间隔 80 ms（可在设置中调整）；显示缓冲超过 40000 / 120000 字符时自动降为 150 / 250 ms
- 终端最大显示缓冲默认 200000 字符（可配置），防止长时间运行内存增长
- 缓冲裁剪时整体重写显示，并带 300 ms 节流，避免大输出期间反复重绘
- **原始输出保存不受显示缓冲裁剪影响**：设备原始输出按原样写入
  `%LocalAppData%\235NetworkAssistant\work\session-<会话>.log`，[保存输出] 复制该文件
- 大输出（`show running-config`、`show mac-address-table`、`show logging`）不得阻塞 UI

## 4.1 CLI 交互（Phase 1）

CLI 页有两种输入模式，工具条上的 **☑终端模式** 一键切换（默认**终端模式**，即 Xshell 那种用法）：

| | 终端模式（默认，像 Xshell） | 行模式 |
| --- | --- | --- |
| 输入位置 | **直接点终端就能打字**，光标在终端里 | 页面下方单独的输入框 |
| 发送时机 | 字符**逐个**发给设备，设备回显就是屏幕上那一行 | 回车 / [发送] 时整行发送 |
| 回车 | 发送结束符（Serial 默认 CR，Telnet 默认 CRLF） | 同左 |
| ↑ / ↓ | 发送 `ESC[A` / `ESC[B`，由**设备**给出历史命令（与 Xshell 一致） | 本地历史：把上一条命令填回输入框 |
| Tab | 发送 `\t` 给设备补全 | 同左 |
| `?` | 直接作为字符发送（设备侧帮助） | 立即把“当前输入 + ?”发给设备 |
| Ctrl+C | 无选中时发送 `0x03`；有选中时复制 | 同左 |
| 粘贴 | Ctrl+V 把剪贴板内容原样发给设备 | 粘贴进输入框，回车再发 |
| 界面差异 | 隐藏下方输入框与[发送]按钮，终端占满整页 | 显示输入框与[发送] |

两种模式共用同一套连接、缓冲与会话留档；终端模式下"看到的输入"来自**设备回显**，
所以如果某台设备不回显，可在工具条勾上 **本地回显** 补充显示。

| 操作 | 行为 |
| --- | --- |
| 回车 / [发送] | 发送当前输入 + 连接参数里的结束符（Serial 默认 CR，Telnet 默认 CRLF） |
| ↑ / ↓ | 调取命令历史（记录进入历史前的输入草稿） |
| Tab | 作为 `\t` 透传给设备做命令补全，不切换焦点 |
| `?` | 立即把“当前输入 + ?”发给设备（锐捷 CLI 的帮助不需要回车） |
| Ctrl+C（无选中文本） | 发送 `0x03` 中断字符；有选中文本时保留复制行为 |
| 清空 | 只清空显示缓冲，会话文件继续记录 |
| 保存输出 | 导出本会话**完整**原始输出（不受显示缓冲上限影响） |
| 自动滚动 / 本地回显 | 可选；本地回显默认关闭（由设备回显，避免重复显示） |

## 5. Command Preview 交互

所有 GUI 配置操作统一流程：

```
GUI 操作 → Command Generator → CommandPreviewWindow
   ├ 操作说明（Description）
   ├ 影响范围（ImpactScope，危险操作必须写明影响端口/业务）
   ├ CLI 命令（纯文本、可复制）
   └ [复制] [取消] [执行]
```

- 只有点击[执行]才发送命令
- 设备未连接时[执行]不可用，只允许复制
- 执行结果显示原始 CLI 输出
- 危险操作（shutdown、删除 VLAN、改 Trunk、批量修改端口）使用红色风险提示
- 绝对不自动执行 `write` / `write memory` / `copy running-config startup-config`
  （V0.2.1 起提供**显式** [保存配置] 按钮：必须按住 1.2 秒确认才发送，仍不存在任何自动保存路径）

## 6. 页面性能

- 页面按需初始化：第一次打开某页时才创建 ViewModel 并加载数据
- 切换页面复用 ViewModel（`NavigationItem.Instance`）
- 不用后台线程持续刷新 UI；只有用户点击刷新才查询设备
- 状态栏时间每秒更新一次（仅一个 DispatcherTimer，Background 优先级）

  - 楼栋筛选对交换机与场所列表同时生效

## 6.2 设备页面（Phase 3）

统一约定：

- 每个页面顶部固定：[刷新]（用户点击触发，绝不自动轮询）+ 解析摘要（解析 N 行 / N 行未识别），
  底部可展开 **原始输出** 面板（可直接复制）
- 解析失败时顶部显示提醒，界面只提供原始输出，不做猜测解析
- 所有配置操作：填参数 → [生成命令并预览] → Command Preview 对话框 → 用户点[执行]才发送

| 页面 | 结构化内容 | 配置能力 |
| --- | --- | --- |
| 端口 | Port / Status / VLAN / Duplex / Speed / Type / LLDP 邻居 | 开启、关闭、Access VLAN、Trunk、速率、双工、介质类型（多选或手工输入端口） |
| VLAN | VLAN ID / Name / Status / 端口数 / Ports | 创建 VLAN、删除 VLAN（危险）、重命名、批量端口划入 Access VLAN |
| Trunk | Port / Mode / Encap / Status / Native / Allowed / Active VLANs | 设为 Trunk、Allowed VLAN add / remove、Native VLAN（危险） |
| LLDP | 本地端口 / 邻居设备 / 邻居端口 / 管理 IP / 更新时间 | [详情] / [Telnet 到邻居] / [查看本地端口]（跳转端口页并预选） |

## 6.4 连接与故障自检（Console / Telnet）

【连接】页的失败提示必须是**能照做的中文**，不允许把 .NET 原生英文/取消信息直接丢给用户：

| 原始情况 | 界面提示（首行） |
| --- | --- |
| 串口不存在（驱动没装 / 没选口） | `串口 COM3 在这台电脑上不存在。请点[刷新串口]，在下拉里选实际存在的那个口…本机当前可用串口：COM1。` |
| 串口被占用 | `串口 COM3 已被占用或没有访问权限。关掉 SecureCRT / PuTTY / 串口助手后重试…` |
| Telnet 对方拒绝 | `192.0.2.10:23 通了，但对方拒绝连接（23 端口没有服务）。请在交换机上开启 Telnet 服务…` |
| Telnet 超时 | `192.0.2.10:23 连接超时（8 秒内没有任何响应）。` + 环境行说明同/不同网段 —— **不同网段不算原因**（跨网段只要有路由就能连），真连不上按：路由 → 防火墙/ACL 放行 TCP → 交换机是否开 Telnet |
| 地址写错 | `地址 192.0.2.999:23 无法解析。请检查 IP 是否输错…` |

每条提示都保留一行 `原始错误：…` 便于追溯，但**中文结论永远在第一行**。

其他连接相关行为：

- 串口下拉只列出**真实存在**的 COM 口（不再把默认 COM1 当成检测结果）；只检测到一个串口时自动选中
- **Console / Serial 与 Telnet 是折叠面板（手风琴）**：初始状态两块都折叠；展开其中一个会自动收起另一个，
  两套连接参数不会同时占满页面（腾出的高度全给地址簿）。点标题即可展开/收起
- 没有任何串口时，Console 面板下面直接提示“先装 USB-Serial 驱动（CH340 / PL2303 / FTDI）”
- 自动登录不再“每等一步算一个超时”：设备已经在 `Ruijie#` 提示符时**直接跳过登录**（< 100 ms 完成连接），
  需要登录时用户名/密码/提示符共用一个时间预算；登录结果以普通色提示显示在按钮下方，同时写进 CLI 页的 `[CLI]` 行
- **连接即识别设备名**：设备提示符本身带主机名（`Example-SW#`、`Example-SW(config)#`），
  连上后顶部状态栏、概览页、CLI 页标题立刻显示真实设备名，不需要用户先点一次 `show` 命令；
  提示符被 TCP 分片切成两次到达也能正确识别（滚动尾部缓冲）
- 已连接但还没识别出主机名时，顶部状态栏显示「**已连接设备** · 192.0.2.10」，不再误显示「未连接设备」
- **[连通性自检]** 按钮（只读探测，不改任何设置），一次给出五项结论：
  串口枚举 → 地址解析 → 本机网段（**仅参考**，同/不同网段只说明走不走网关）→ Ping → Telnet 端口探测。
  **只有「Telnet 端口」那一行才是"能不能连"的结论**（它真的发起一次 TCP 连接；跨网段可连，不需要同网段）
- 本地数据目录不可写（磁盘满 / 目录被策略锁住）时，CLI 页**仍然可以正常使用**，
  只在终端里提示「原始输出无法写入磁盘…[保存输出]不可用」，不会出现“点 CLI 没反应”
- **CLI 未确认时可以直接在终端里手动登录**：把用户名/密码当作普通命令逐行敲进去即可；
  设备一旦回出提示符（`Host#`），界面会自动从「已连接（CLI 未确认）」切到「已连接」并识别设备名。
  终端只回显设备返回的内容，密码不会被本地回显（避免密码明文留在终端里）

状态语义（连接页 / 顶栏 / CLI 页统一）：

| 界面显示 | 含义 | 能不能用 |
| --- | --- | --- |
| 连接中 | 正在 TCP 握手 / 打开串口 | 不能 |
| 已连接（正在登录） | 底层已连上，正在自动登录 | 能（可切到 CLI 手动操作） |
| 已连接（CLI 未确认） | 底层已连上，但没等到提示符（登录超时 / 设备无输出） | 能，按钮下方给出原因 |
| **已连接** | 已看到提示符，CLI 就绪 | 能 |
| **连接失败** | **只有**底层连不上（TCP 拒绝/超时、串口打不开）才是这个状态 | 不能 |

即：**登录失败、提示符超时一律不算“连接失败”**，只会在连接页用普通色提示原因。

```
✓ 串口 · COM3 存在（共检测到 1 个串口）。
✓ Telnet 地址 · 192.0.2.49
! 本机网段 · 本机网卡：192.0.2.23/24；与目标同网段。
! Ping · 192.0.2.49 ping 不通（TimedOut）。很多交换机会禁用 ping，这本身不代表 Telnet 一定不通。
✗ Telnet 端口 23 · 192.0.2.49:23 通了，但对方拒绝连接（23 端口没有服务）。…
```

## 7. 界面验收

Phase 0 通过诊断参数直接渲染界面图片，无需人工截图：

```
--shell-check                          仅校验 XAML/绑定/布局
--ui-snapshot=<path.png>               输出主界面快照（默认概览页）
--ui-page=<key> --ui-snapshot=<path>   输出指定页面快照（connection / resources / settings / CLI / …）
--ui-size=<宽x高>                      指定快照尺寸，用于验证小屏布局（例：--ui-size=860x480）
--ui-font=小|标准|大                   临时套用界面字体档位（不写回设置），验证大字体下的布局
--ui-focus                             快照时进入专注 CLI 模式
--ui-type=<命令>                       连接后在 CLI 页真的“敲一条命令并回车”，等设备回显再出快照
--ui-page=commandpreview --ui-snapshot=<path>  输出 Command Preview 对话框快照
```

每次输出快照时会同时生成 `<path>.log`，其中包含**布局裁切检查**结果：列出被窗口裁掉、
且没有任何可见滚动条可以滚到的元素（正常情况下应为“没有被裁切的元素”），
以及页面里实际可滚动的区域。可用于自动化验证“小窗口下信息不丢失”。

带 `--ui-type` 时日志里还会多出 **CLI 输入自检** 结果（连接状态、发送的命令、输入框是否清空、
终端长度变化、是否包含命令回显、↑ 能否取回上一条命令、终端内容尾部），
用于自动化验证「连接后 CLI 能不能正常输入」。

## 8. 小屏 / 外勤设备适配（Small Screen First）

目标：在 1280×720、1366×768 等小工作区，以及 Windows 100% / 125% / 150% 缩放下，
重要信息仍然完整可见、不需要频繁横向滚动、CLI 有足够空间。

### 8.1 断点与自动行为（纯 WPF 布局，无响应式框架）

| 条件 | 行为 |
| --- | --- |
| 窗口宽度 < 1180 DIP（约等于 1366 物理像素 + 125% 缩放） | 左侧导航自动折叠为**仅图标**，ToolTip 显示名称 |
| 用户手动点过导航开关 | 本次运行不再自动改变（尊重用户选择） |
| 页面可用宽度 < 960 DIP | DataGrid **次要列自动隐藏**（重要列保留，列宽仍可拖动） |
| 窗口最小尺寸 | 860×480 DIP（150% 缩放下的 1366×768 屏幕仍可完整使用） |

### 8.2 各区域的小屏策略

- **顶部状态栏**：单行显示 `🟢 设备名 · 管理地址`；连接方式、连接状态、Session 收进 ToolTip，绝不占两行
- **专注 CLI 模式**（`Ctrl+L` 或页面按钮）：隐藏导航、顶部品牌文字与底部状态栏，终端获得最大垂直空间；
  CLI 页面头部与设计提示同时隐藏，只保留工具条 + 终端 + 输入行；`Esc` 或再次点击[退出专注]返回
- **主列表 + 选中项详情**：端口、VLAN、LLDP、MAC/IP、设备页面都提供详情面板，
  小屏下无需横向滚动即可看到完整字段
- **信息优先级**：VLAN 列表占据主要可视区域；创建/删除、重命名、批量端口操作收在默认折叠的“VLAN 配置操作”中，避免配置表单挤压查询结果。MAC/IP 页刷新按钮与下方 ARP（默认）、MAC、DHCP Snooping 标签顺序一致
- **长页面整页竖向滚动**：内容比窗口高的页面（当前为【设置】）整页包裹竖向 `ScrollViewer`，
  窗口不够高时右侧出现滚动条，保证“关于 / 导入预览”等信息一定能滚到；
  窗口足够高时不出现滚动条，内容仍然撑满（不出现空白），表格自身的高度上限为 420 px，由表格自己滚动
- **按钮**：工具条统一改为可换行的 `WrapPanel`，小屏自动折行；配置表单同样自动换行，避免溢出
- **字体**：设置 → 外观 提供 **界面字体 / CLI 字体**（小 / 标准 / 大）两档独立设置，默认“标准”，可读性优先，
  不会为了塞内容而全局缩小字号
- **弹窗（Command Preview）**：窗口尺寸受工作区限制（`MaxHeight = 工作区高度 - 24`），
  说明固定、命令区域内部滚动、底部按钮固定；`Esc` 关闭，`Enter` 仅在操作**不危险**时触发执行

### 8.3 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+C` | 任意页面快速回到 CLI |
| `Ctrl+F` | 聚焦当前页面的第一个输入框（搜索框 / CLI 输入框） |
| `Ctrl+L` | 切换专注 CLI 模式 |
| `Esc` | 退出专注模式；Command Preview 中关闭对话框 |
| CLI 内：`Enter` / `↑` `↓` / `Tab` / `?` / `Ctrl+C` | 发送 / 命令历史 / 透传补全 / 立即提问 / 发送 0x03 |

### 8.4 DPI 与性能

- 窗口尺寸、断点判断全部使用 DIP；表格行、表单行高使用 `Auto`，125%/150% 缩放下文字不被裁切
- 响应式只依赖 `SizeChanged` + 附着属性切换 `Visibility`，**没有动画、没有高频 Timer、没有后台任务**，
  不引入任何第三方 UI 框架

### 8.5 小屏布局验收结果

用 `--ui-size` + `<path>.log` 的裁切检查逐页验证（12 个页面 × 尺寸 × 字体档位）：

| 尺寸 | 界面字体 | 结果 |
| --- | --- | --- |
| 860×480（最小窗口） | 标准 | 12/12 页面无裁切 |
| 1000×560 | 标准 / 大 | 12/12 页面无裁切 |
| 1280×760（默认尺寸） | 标准 | 12/12 页面无裁切（【设置】页出现竖向滚动条，可滚 273 px） |
| 1280×1080 | 标准 | 12/12 页面无裁切，且无多余滚动条 |
